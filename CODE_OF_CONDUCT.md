# Code of Conduct

## Our commitment

AudioFerry contributors, maintainers, and users are expected to help keep the project welcoming, respectful, and safe for everyone, regardless of experience level or personal background.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on the code, documentation, or behavior being discussed.
- Assume good intent while remaining clear about technical and safety concerns.
- Protect other people's privacy. Redact IP addresses, usernames, device names, credentials, and raw logs before posting.
- Accept reasonable moderation decisions and corrections.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Sexualized language or unwanted attention.
- Trolling, sustained disruption, or deliberately misleading reports.
- Publishing another person's private information without permission.
- Encouraging unsafe software distribution, security bypasses, or copyright infringement.

## Reporting and enforcement

For ordinary project problems, use the appropriate GitHub issue template. Do not publicly disclose sensitive conduct or security reports. Contact the maintainer privately through the contact methods on the maintainer's GitHub profile and follow [SECURITY.md](SECURITY.md) when the report involves a vulnerability.

Maintainers may edit or remove contributions, comments, issues, or other participation that violates this code. Depending on severity and history, enforcement may range from a private warning to a temporary or permanent ban from project spaces.

## Scope

This code applies in AudioFerry project spaces and when someone is publicly representing the project.
