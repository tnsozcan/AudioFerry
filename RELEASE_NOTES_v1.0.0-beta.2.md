# AudioFerry v1.0.0-beta.2

Licensing release for Windows. The application is functionally the same as v1.0.0-beta.1.

## Changes

- AudioFerry is now licensed under the PolyForm Noncommercial License 1.0.0 instead of MIT. Personal and other noncommercial use stays free; selling AudioFerry or using it commercially is not permitted. See `LICENSE`.
- Third-party notices and the dependency inventory were regenerated for this build. Dependencies keep their own licenses.

## Verification status

The same static checks and offline tests as v1.0.0-beta.1 were run for this build, together with a packaged startup check. Audio playback behavior is unchanged from v1.0.0-beta.1, which was verified on real HomePod hardware; extended-playback dropouts and multiple receiver versions still need more testing.

The executable is unsigned and can trigger Microsoft Defender SmartScreen. Verify the release ZIP against `SHA256SUMS.txt` before running it.
