# Contributing to AudioFerry

1. Use 64-bit Python 3.11 on Windows and create a virtual environment.
2. Install `requirements-dev.txt`.
3. Make a focused change and run `scripts\verify.ps1`.
4. For AirPlay changes, report the receiver type and whether discovery, connection, playback, stop, and reconnect were each tested.

Do not publish real `bridge_config.json` files or raw logs. Replace private IP addresses, Windows usernames, HomePod names, and audio-device names with neutral examples. Do not include copyrighted Apple artwork or third-party binaries without confirming redistribution rights.
