# Security Policy

## Supported versions

Only the latest `1.0.0-beta.x` release receives security fixes while the project is in beta.

## Reporting a vulnerability

Until a private reporting address is published, do not open a public report containing an exploit, private IP address, device name, username, credential, or raw log. Contact the maintainer through a private channel listed on the future project profile and provide a redacted reproduction.

AudioFerry should not need administrator privileges. It captures local system audio and sends it to a receiver selected on the local network. It has no telemetry or update downloader. Treat unexpected requests for administrator access, external Internet access, or downloaded executables as suspicious.
